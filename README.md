Student Registration System
Overview

This project is a Java-based Student Registration System developed to demonstrate object-oriented programming concepts, data structures, and student management functionality.

The system allows management of student records, department-based filtering, sorting operations, and registration queue simulation.

Features
Add and manage student records
Display all registered students
Search/filter students by department
Sort students alphabetically
Simulate student registration queues
Demonstrates Java Collections Framework usage
